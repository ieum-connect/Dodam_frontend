# 성장 그래프 산술평균 자료

- 통계작성기관: 국민건강보험공단, 2024 건강검진통계, 전국 영유아 수검자.
- 키: KOSIS DT_35007_N131, 몸무게: DT_35007_N133.
- 원표 링크는 src/growthReference.js의 growthReferenceSources 참고.
- 수치 확인: 육아정책연구소 「영유아 주요 통계」 표 4-2/4-3 (2024), KOSIS 인출일 2026-08-25.
  https://repo.kicce.re.kr/bitstream/2019.oak/6089/2/ES2601.pdf
- 2026-11-17 확인한 성별 행을 원문 소수점 둘째 자리 그대로 옮김. 전체 행이나 남녀 평균을 재평균하지 않음.
- 신생아 14~35일, 4~6 / 9~12 / 18~24 / 30~36 / 42~48 / 54~60 / 66~71개월의 구간별 산술평균.
- 월령은 측정일의 만 월령. 신생아 구간은 생후 경과 일수. 비교 카드는 모든 날짜에서 그래프와 동일한 선형 보간값을 추정 평균으로 명시. 원자료 범위 밖 또는 성별·생년월일 누락 시에는 비교 불가. 50백분위로 대체하지 않음.
- 그래프는 각 구간의 날짜 중간점에 평균을 놓고 선형 보간해 연속 점선으로 표시. 범례에 구간 사이 추정임을 명시하며 월별 실측 평균으로 표현하지 않음. 첫/마지막 중간점과 원자료 범위 끝 사이는 동일 값으로 유지하고, 원자료 범위 밖은 외삽하지 않음. 전체 곡선을 만든 뒤 조회 기간으로 잘라 동일 날짜의 값이 변하지 않음. 비교 카드에는 선택한 날짜의 추정 평균을 표시해 그래프와 값을 일치시킴.
- 이는 전체 아동 모집단 평균이나 매월별 평균이 아니며, 건강 상태를 판정하는 기준선도 아님.
- 기존 growthReferenceData.json의 2017 백분위 데이터는 이 화면에서 더 이상 import하거나 비교에 사용하지 않음.
