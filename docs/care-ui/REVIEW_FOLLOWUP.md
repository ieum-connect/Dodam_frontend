# 리뷰 반영 확인

- 성장 API는 현재 측정일 내림차순으로 반환합니다. 화면에서도 응답을 복사해 내림차순으로 정렬하여 최근 값과 이력 순서가 서버 정렬에 의존하지 않도록 했습니다. 그래프는 별도로 오름차순을 유지합니다.
- 새 반복 복약은 `createMedicationSeries`를 호출합니다. 종료일 지정은 `endDate`, 무기한 반복은 `endDate: null`을 전달합니다.
- `createScheduleBatch`는 단일 일정 등록에서 `repeatDays: 1`로만 사용합니다. 이 호출에 구버전의 31일 제한이 있어도 새 반복 복약에는 적용되지 않습니다.
- 통합 타임라인과 캘린더는 월 단위로 일정을 조회합니다. 백엔드 #30의 쓰기 트랜잭션 및 92일 조회 제한과 호환됩니다.
- 자동 검증: 성장/타임라인 테스트 9개 통과, 프로덕션 빌드 통과. 이번 수정은 정렬 로직이며 화면 배치 변경은 없습니다.
