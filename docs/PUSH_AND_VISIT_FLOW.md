# 푸시 알림과 기록 연결 검증

## 사용 흐름
알림 목록 → 설정 → 이 기기 알림 켜기에서 알림 권한을 허용한다.
Firebase 웹 설정은 백엔드 /api/push/config에서 받는다. 프론트에 서버 비밀키를 저장하지 않는다.
기존 /sw.js를 공유하며 푸시 클릭 시 알림 목록을 연다. 로그아웃·계정 전환 시 기기를 해제한다.
운영에서는 HTTPS가 필요하다. 로컬 개발 시 DODAM_BACKEND_URL로 프록시 대상을 지정할 수 있다.

## 방문 기록 연결
홈의 오늘 건강 일정과 공통 캘린더에 방문 날짜 기준으로 병원 기록을 함께 표시한다.
방문 완료/예약 상태와 시간 정보 없음을 구분하며 별도의 일정이나 푸시를 생성하지 않는다.
방문 상세 → 연결 문서 → 문서 상세 → 원본 보기로 이동한다.
방문·연결 문서는 커서 페이지를 끝까지 조회한다. 복약 전용 목록에는 병원 기록을 섞지 않는다.

## 2026-11-10 로컬 검증
- npm run build 통과. push.js 정적/동적 import 혼용 경고는 남아 있음(빌드 실패 아님).
- PC Chrome 실제 복약·일정 푸시 2건 수신과 클릭 후 알림 목록 진입: 사용자 확인.
- 홈 → 공통 캘린더 → 방문 상세 확인.
- 개인정보 없는 PNG 업로드 → 연결 문서 클릭 → 원본 이미지 열림 확인.
- 원본 응답과 업로드 파일의 SHA-256 일치.
- AI 서버 연결을 비활성화하여 유료 AI 호출 없이 원본 조회 검증.
- 휴대폰 설치 PWA 수신 및 운영 배포 후 검증은 미실행.
